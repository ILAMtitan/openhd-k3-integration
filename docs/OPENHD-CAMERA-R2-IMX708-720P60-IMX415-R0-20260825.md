# OpenHD BeagleY-AI camera R2: IMX708 720p60 + IMX415 R0

Date: 2026-08-25

This branch is the combined camera-development stack after finalizing the IMX708
source/output contract at 720p60 and then layering the pre-hardware IMX415 work
on top.

## Camera types

- type 150: TI J722S IMX219 (preserved)
- type 151: TI J722S IMX708, finalized R2 path
- type 152: TI J722S IMX415, pre-hardware R0 path

The clean-install BeagleY default remains IMX708/type 151. Installing the
IMX415 checkpoint explicitly changes the persisted primary camera to type 152
for that test unit only.

## Patch order

The order is deliberate and reproducible:

1. patches 0001..0008: qualified BeagleY/OpenHD R3 base
2. patch 0009: native TI J722S IMX708/type151 base
3. patch 0010: IMX708 1536x864p60 -> VISS -> 1280x720p60
4. patch 0011: IMX415/type152 full-array -> VISS -> 1280x720p30

This makes IMX415 depend on the finalized 720p60 camera stack rather than the
older 2304x1296p56 IMX708 checkpoint.

## IMX708 R2

```
IMX708 1536x864 RAW10 @ ~60 (VBLANK=946)
  -> VPAC/VISS 1536x864 NV12 @ 60
  -> TIOVX multiscaler
  -> 1280x720 NV12 @ 60
  -> Wave5 H.264 @ 6 Mbit/s / GOP30
  -> OpenHD RTP
```

The sensor itself generates the ~60-fps cadence; there is no `videorate`
frame-drop stage.

## IMX415 R0

```
IMX415 3864x2192 GBRG10 @ nominal 30
  -> VPAC/VISS 3864x2192 NV12 @ 30
  -> TIOVX multiscaler
  -> 1280x720 NV12 @ 30
  -> Wave5 H.264 @ 6 Mbit/s / GOP15
  -> OpenHD RTP
```

IMX415 remains pre-hardware-qualified. AE/AWB remain disabled and no default
manual exposure/gain values are invented.

## Matching accelerator branch

```

```

That branch contains both the finalized IMX708 720p60 platform helpers and the
IMX415 overlays/module/DCC/VISS/Wave5 bring-up helpers.

## Qualification order

Finish IMX708 before enabling IMX415:

1. generate/install IMX708 1536x864 DCC
2. raw 600-frame 864p60 cadence test
3. IMX708 VISS 1536x864p60 smoke
4. IMX708 VISS -> multiscaler -> Wave5 1280x720p60 smoke
5. install/start OpenHD type151 and verify RF 720p60
6. only then switch camera hardware/overlay to IMX415
7. qualify IMX415 RAW -> VISS -> multiscaler -> Wave5 locally
8. install OpenHD type152 and verify RF

No EdgeAI memory-map, remoteproc firmware, or qualified RAW10LE compatibility
runtime changes are introduced by this combined branch.
