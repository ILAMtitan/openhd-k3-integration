# OpenHD BeagleY-AI IMX708 720p60 R2 checkpoint

Date: 2026-08-25

This checkpoint keeps camera type 151 and converts the native TI J722S IMX708
pipeline from the qualified R1 2304x1296p56 path to the intended OpenHD
1280x720p60 output.

## Source cadence

The matching accelerator checkpoint configures the IMX708 1536x864 binned mode
with VBLANK=946. With the driver's 566.4 MHz pixel rate and 5216-pixel line
length this yields approximately 59.9939 fps, so OpenHD does not need a
`videorate` frame-drop stage.

## OpenHD type 151 R2 pipeline

```
v4l2src /run/ti-k3/camera-video, dmabuf-import
  -> rggb10le 1536x864 @ 60
  -> capssetter -> legacy rggb10 metadata
  -> tiovxisp / VPAC VISS
       compatibility registry slot SENSOR_SONY_IMX219_RPI
       IMX708 DCC 1536x864
       format-msb=9
       AE disabled
       AWB disabled
  -> NV12 1536x864 @ 60
  -> tiovxmultiscaler target=0
  -> NV12 1280x720 @ 60
  -> queue depth 1, leaky downstream
  -> Wave5 H.264
       6 Mbit/s
       GOP 30
  -> OpenHD H.264 parser / RTP MTU 1024 / appsink
```

The user-visible registry mode for `TI_J722S_IMX708` is now 1280x720@60.

Six Mbit/s is retained from the physically clean RF checkpoint. The lower
720p frame size provides substantially more bits per output pixel than the R1
2304x1296p56 stream at the same link bitrate. Dynamic Wave5 bitrate control
remains future work.

## Patch layering

The R2 branch keeps the R1 patch as the validated foundation:

- 0009: add native IMX708/type 151, TI appsink behavior, 6-Mbit/s RF baseline
- 0010: move IMX708 to native 1536x864p60 capture and TIOVX 1280x720p60 output

This keeps the original R1 qualification diff auditable instead of rewriting
it in place.

## Live prerequisites

The matching accelerator branch is:

```
ILAMtitan/ti-k3-accelerators
imx708-720p60-r2-20260825
```

Before applying OpenHD R2, install and qualify:

```
/opt/imaging/imx708/linear/dcc_viss_1536x864.bin
/opt/imaging/imx708/linear/dcc_2a_1536x864.bin
```

Then run the accelerator-side local hardware test:

```
FRAMES=600 ti-k3-imx708-wave5-720p60-smoke
```

Only after that passes should OpenHD be installed:

```
sudo ./apply-imx708-checkpoint.sh
sudo systemctl start openhd.service
sudo ./verify-imx708-checkpoint.sh
```
